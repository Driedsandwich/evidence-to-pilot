# M5 handoff

## What works

- TypeScript CLI using Mozaik 4.1.0, pinned exactly in the existing lockfile. Node 20+ is required by the installed Gemini SDK.
- Local lexical retrieval with work-side researcher IDs; concurrent Company Analyst and Research Profiler loops; validated shared state; Writer and bounded Critic review/correction.
- Record/field/quote evidence checks, complete claim-path review coverage, explicit proposal labels, bounded claim removal and honest accepted/no-match/stopped outcomes.
- Shared provider concurrency, rate, call and estimated-cost limits, bounded retries and per-task trace/overlap reporting.
- Recommended live defaults now match the successful mixed-model configuration: Anthropic Haiku analysts, Sonnet Writer/Critic. Gemini Flash is the alternative. Each role has a model override; precedence is role override, global MODEL, then provider/role default.
- A fresh-clone demo needs only `npm ci` and `npm run demo`. It builds and runs tiny authored fixtures without credentials or the organizer dataset. The ordinary CLI still requires an explicit local dataset.

## Evidence and what is mocked

[Live-8](runs/live-8/summary.json) contains three accepted proposals for C001/R1008, C025/R0637 and C036/R0976, all after one real Critic-requested revision. The full trace records 22 provider attempts, peak concurrency 2, 315.099 seconds between run start and finish and $1.181064 estimated accounted cost. The estimate uses shared $3/$15 input/output rates per million tokens; it is not an invoice. The [README](README.md#real-live-result-three-challenges-three-accepted-proposals) links every brief, evidence ledger and review history.

Live-1 through live-8 remain unchanged. Earlier failures include unsupported quotes, incomplete reviews, schema/provider errors, rate limits and review exhaustion. Across eight runs, four of 22 challenge attempts were accepted. These development runs are not a controlled benchmark. M5 read the existing artifacts; it made no provider calls.

`npm run demo` uses scripted findings, three domain-specific proposal templates and a scripted Critic. It exercises the real runtime, shared state, mechanical validation and correction path; it cannot establish semantic quality. Its authored IDs are C901/R9001, C902/R9002, C903/R9003 and the C999 no-match. It intentionally injects an unsupported quote into each first matched draft. The [historical organizer-snapshot mock](docs/demo/README.md) is a separate example and is not regenerated by that command.

## Run and verify

```bash
# Fresh clone only; reuse dependencies if already installed.
npm ci
npm run demo
npm test
npm run trace -- out/<run-id>/trace.jsonl
```

For live inference, download the organizer snapshot once with `npm run data:download`, then `npm run build`. Privately configure `.env` from `.env.example`: `PROVIDER=anthropic`, `ANTHROPIC_API_KEY`, and blank `MODEL`/role overrides use Haiku for both analysts and Sonnet for Writer/Critic. Existing overrides must be cleared to select those defaults. Review budget and planning rates before paid calls.

```bash
npm run run -- --mode live --challenges C001-CH1,C025-CH1,C036-CH1 --out out
npm run trace -- out/<run-id>/trace.jsonl
```

For Gemini, set `PROVIDER=gemini`, supply `GEMINI_API_KEY` privately, and clear Anthropic model overrides; all four roles then default to `gemini-3.5-flash`. The CLI remains mock unless `--mode live` is explicit. Live reproduction is nondeterministic and is not guaranteed to accept the same pairs.

See [VERIFICATION.md](VERIFICATION.md) for M5's executed commands and results. Dependency installation and data download were not repeated for this offline change. All changes remain in the working tree for review; no commit was made.
