# evidence-to-pilot

Entry for the NTP Novi Sad AI Hackathon by JigJoy (track: EINSTEIN Science-to-Business Matchmaker), built on Mozaik.

Agents that find researcher-company pairs worth a joint project and write evidence-backed proposals.

Work in progress during the hackathon (30-31 October 2026).

## Scope of work

The code in this repository is written during the event. `docs/prep/` holds research notes and test material prepared before the event.
